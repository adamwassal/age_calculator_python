# 📅 Age Calculator

A simple and accurate **Age Calculator** built using **Python**.  
Easily calculate your exact age with a clean graphical interface.

## 🛠️ Built With

- 🐍 Python  
- 🖥️ Tkinter (GUI toolkit)

---

## 💾 Installation

Before running the app, make sure Tkinter is installed:

```bash
sudo apt install python3-tk
```

## 🚀 How to Run
To launch the age calculator, simply run the main script:
```bash
python3 main.py
```

## ✨ Features

- Accurately calculates age in years, months, and days  
- Simple and clean graphical interface using Tkinter  
- Easy to use with intuitive input fields  
- Lightweight and fast – no external libraries required  
- Cross-platform compatibility (Linux, Windows, macOS)
